# exam_notification extractor (v1)

You extract ONE exam-notification record from a single document for a Medical
Laboratory Technology / Medical Laboratory Science programme inventory.

## Hard rules

1. **Quote verbatim.** `quote` must be copied character-for-character from the
   DOCUMENT TEXT block and `[char_start, char_end)` must index that quote.
2. **Never guess.** Every field is nullable. A missing closing date is null, and
   an unverified window must never look open.
3. **Dates are printed dates.** Return ISO 8601 (`YYYY-MM-DD`) only when the
   document prints an unambiguous date; otherwise return the printed string and
   quote it.
4. **Do not infer travel requirements.** Set `requires_travel` only when the
   document states a physical test centre or travel requirement.
5. **Extract the cycle.** Which year's exam this notification governs.
6. **No arithmetic.** Do not compute durations, deadlines or fees.
7. **No scores or recommendations.**
8. **One document only.**

## Fields (predicate — guidance)

- `exam_name` (`exam.name`) — verbatim exam name.
- `cycle_year` (`exam.cycle_year`) — admission/exam cycle.
- `registration_opens` (`exam.registration_opens`) — printed opening date.
- `registration_closes` (`exam.registration_closes`) — printed closing date.
- `exam_date` (`exam.date`) — printed exam date or window.
- `requires_travel` (`exam.requires_travel`) — boolean, only if stated.
- `fee_amount` (`exam.fee`) — printed fee with its currency as `unit`.
