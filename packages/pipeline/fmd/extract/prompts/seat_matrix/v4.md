# seat_matrix extractor (v4, row-scoped quote-first)

You extract ONE seat-matrix record from a single document for a Medical
Laboratory Technology / Medical Laboratory Science programme inventory.

## Output contract

For every field return either `null` or an object with EXACTLY these keys —
nothing else:

```json
{"quote": "<verbatim text from DOCUMENT TEXT>", "context": "<row identifier or null>", "confidence": 0.0, "reason_if_null": null}
```

Return ONLY `quote`, `context`, `confidence`, `reason_if_null`. Never emit
`value`, `unit`, `char_start` or `char_end`, and never emit a computed value:
counts are parsed downstream from the quote. `context` is optional and only
disambiguates a location — it is never evidence for a value.

## Table discipline

A seat matrix repeats the same programme label and the same number once per
college. `"B.Sc. Medical Laboratory Technology 20"` alone is not a location —
it occurs on eighteen rows. **The quote must contain the value** (the printed
number with the words printed next to it: the programme label, the quota label
or the row label) and **the context must contain the row identifier** — the
institute name for an intake row, the programme label for a quota row, and the
column header (sanctioned / admitted / government / management) when several
numeric columns sit side by side; together they must identify exactly one location.
Repeated rows stay distinguishable only through the context. Never
put the number in `context`, and never use a page title or a document heading
as context.

## Money discipline

This family has no money fields. If a fee amount is printed inside the matrix,
it belongs to the fee_structure family — never put it in a seat count. (A
money answer anywhere must carry the printed currency AND the printed period
(year / semester / month); if either is not printed, it is null — that is not
this family's job.)

## Rate discipline

This family has no rate fields. If the matrix prints a reservation percentage
("OBC: 27%"), that rate must state its denominator, else it is null — and you
must never convert a percentage into a seat count.

## Hard rules

1. **Quote verbatim.** Copy the printed number with the words printed next to
   it. Copy the institute name, programme-row label or column header exactly
   into `context`. If you cannot copy both exactly, return null.
2. **Never guess. Null is a correct answer.** Every field is nullable.
   **Never compute, convert or infer.** No arithmetic and no annualising: do
   not sum quotas, reconcile mismatches, scale a row to an institution total,
   or turn a percentage into seats. A blank cell is null, not zero.
3. **Read the row, not the page total.** Quote the seats printed for the named
   programme row; never substitute an institution-wide total.
4. **Sanctioned vs admitted are different columns.** `total_seats` is the
   sanctioned/intake capacity the matrix prints; `admitted` is the filled or
   admitted count, only when the matrix prints one. Never copy one into the
   other, and never reconcile a mismatch between them.
5. **Duration only as printed.** `duration_months` is the programme duration
   printed in months on the matrix or its legend (e.g. "Duration (months): 24").
   Do not convert years or semesters into months; if the document prints
   "2 years", leave `duration_months` null.
6. **Extract the intake year.** Quote the admission cycle the matrix covers.
7. **No scores or recommendations.** You extract claims only; scoring is a
   separate deterministic stage.
8. **One document only.** Do not merge values from other documents.

## Fields (predicate — guidance)

- `intake_year` (`seats.intake_year`) — admission cycle.
- `programme_name` (`seats.programme_name`) — verbatim programme label; use the
  institute as context.
- `total_seats` (`seats.total`) — printed sanctioned intake; context is the
  institute name (and the column header if the row has several numbers).
- `admitted` (`seats.admitted`) — printed admitted/filled seats for that row,
  when the matrix has such a column.
- `duration_months` (`seats.duration_months`) — printed programme duration in
  months, when the matrix states it; null when unstated or printed in years.
- `government_quota` (`seats.government_quota`) — printed government/state
  quota; context is the institute or programme row.
- `management_quota` (`seats.management_quota`) — printed management/NRI/paid
  quota; context as above.
- `quota_note` (`seats.quota_note`) — verbatim wording of the quota split.


## Worked table-row example

Document text — two colleges with identical numbers; only the context picks
one row:

```
S.N / Name of the Institution / Course / Sanctioned / Admitted / Duration (months)
1 / Madras Medical College, Chennai / 3. B.Sc. Medical Laboratory Technology / 20 / 18 / 24
2 / Stanley Medical College, Chennai / 3. B.Sc. Medical Laboratory Technology / 20 / 18 / 24
```

Extracting the Stanley row:

```json
{
  "intake_year": {"quote": null, "context": null, "confidence": null, "reason_if_null": "no admission cycle printed on this page"},
  "programme_name": {"quote": "3. B.Sc. Medical Laboratory Technology", "context": "Stanley Medical College, Chennai", "confidence": 0.9, "reason_if_null": null},
  "total_seats": {"quote": "3. B.Sc. Medical Laboratory Technology 20", "context": "Stanley Medical College, Chennai", "confidence": 0.9, "reason_if_null": null},
  "admitted": {"quote": "Admitted 18", "context": "Stanley Medical College, Chennai", "confidence": 0.85, "reason_if_null": null},
  "duration_months": {"quote": "Duration (months) 24", "context": "Stanley Medical College, Chennai", "confidence": 0.8, "reason_if_null": null},
  "government_quota": {"quote": null, "context": null, "confidence": null, "reason_if_null": "the matrix prints sanctioned and admitted only"},
  "management_quota": {"quote": null, "context": null, "confidence": null, "reason_if_null": "the matrix prints sanctioned and admitted only"},
  "quota_note": {"quote": null, "context": null, "confidence": null, "reason_if_null": "no quota wording on this page"}

```

Every numeric quote occurs on both rows — `context` ("Stanley Medical College,
Chennai") is what makes each one cell, and the column header keeps sanctioned
(20) and admitted (18) apart. Never reconcile 18 with 20 and never copy one
into the other.
