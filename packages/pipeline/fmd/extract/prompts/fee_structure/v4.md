# fee_structure extractor (v4, row-scoped quote-first, period-guarded)

You extract ONE fee-structure record from a single document for a Medical
Laboratory Technology / Medical Laboratory Science programme inventory.

## Output contract

For every field return either `null` or an object with EXACTLY these keys —
nothing else:

```json
{"quote": "<verbatim text from DOCUMENT TEXT>", "context": "<row identifier or null>", "confidence": 0.0, "reason_if_null": null}
```

Return ONLY `quote`, `context`, `confidence`, `reason_if_null`. Never emit
`value`, `unit`, `char_start` or `char_end`, and never emit a computed value:
the amount, currency and period are parsed downstream from the quote.
`context` is optional and only disambiguates a location — it is never evidence
for a value.

## Table discipline

Fee tables print the same amount on many rows and under several columns.
`"Tuition fee 85000"` alone is not a location. **The quote must contain the
value** (the label and the printed amount, plus the currency and period words
where the table prints them) and **the context must contain the row
identifier** — the programme name, the category row, or the column header
(tuition / hostel / mess / exam) when fee columns sit side by side;
together they must identify exactly one location. Repeated rows stay
distinguishable only through the context. Never put a number in `context`.

## Money discipline

A money answer must carry the printed currency AND the printed period
(year / semester / month):

* Quote `₹`, `Rs.`, `INR` as printed; do not convert and do not assume a base
  currency. If the currency is only in the column header, quote the amount and
  put the header in `context` (and fill `currency` from the header wording).
* Quote the period words ("per annum", "per semester", "per year") with the
  amount, or capture them in `fee_period`. **If the period is not printed
  anywhere in the document, the money answer is null.**
* **If either the currency or the period is not printed, return null.** A
  blank cell is null, never zero.

## Rate discipline

This family has no rate fields. If the page prints a percentage or count-rate
("scholarship: 50%"), a rate must state its denominator, else it is null — and
a percentage is never a fee amount: do not put it in any money field.

## Hard rules

1. **Quote verbatim.** Copy the label, the printed amount and, where printed,
   the currency and period words. Copy the programme label, category row or
   column header exactly into `context`. If you cannot copy both exactly,
   return null.
2. **Never guess. Null is a correct answer.** Every field is nullable.
   **Never compute, convert or infer.** No arithmetic and no annualising: do
   not annualise a semester fee, do not sum components into a total (unless
   the document prints that total — then quote the printed total), do not
   convert currency.
3. **No scores or recommendations.** You extract claims only; scoring is a
   separate deterministic stage.
4. **One document only.** Do not merge values from other documents.

## Fields (predicate — guidance)

- `academic_year` (`fee.academic_year`) — e.g. "2025-26".
- `currency` (`fee.currency`) — printed currency, if stated separately.
- `fee_period` (`fee.period`) — the printed fee period as one word: "year",
  "semester" or "month". Fill it whenever the document states the period
  anywhere; it is what saves a cell-level amount whose own quote omits it.
- `tuition_amount` (`fee.tuition`) — printed tuition for the stated period.
- `hostel_amount` (`fee.hostel`) — printed hostel rent, if separate.
- `mess_amount` (`fee.mess`) — printed mess/food charge, if separate. Never
  fold mess into hostel or tuition: quote only a printed mess figure.
- `other_amount` (`fee.other`) — any other printed fee (transport, internet,
  sports, misc) that is not tuition, hostel, mess or the mandatory academic
  fees below.
- `mandatory_fees` (`fee.mandatory`) — mandatory non-tuition academic fees
  (exam, library, laboratory, development) only if printed.
- `total_first_year` (`fee.total_first_year`) — only when the document prints a
  first-year total.
- `fee_period_note` (`fee.period_note`) — verbatim phrase fixing the period
  when `fee_period` cannot be reduced to one word.
