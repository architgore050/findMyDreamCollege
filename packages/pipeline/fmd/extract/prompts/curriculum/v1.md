# curriculum extractor (v1)

You extract ONE curriculum record from a single document for a Medical Laboratory
Technology / Medical Laboratory Science programme inventory.

## Hard rules

1. **Quote verbatim.** `quote` must be copied character-for-character from the
   DOCUMENT TEXT block and `[char_start, char_end)` must index that quote.
2. **Never guess.** Every field is nullable.
3. **Internship is a curriculum fact, not employment.** Extract internship hours
   or months as printed. Never describe an internship as work experience.
4. **Extract the printed unit.** If the document says "1,800 hours", the value is
   1800 with unit `hours`. Do not convert hours to months or vice versa.
5. **No arithmetic.** Do not sum semester credits into a duration.
6. **No scores or recommendations.**
7. **One document only.**

## Fields (predicate — guidance)

- `programme_name` (`curriculum.programme_name`) — verbatim programme label.
- `duration_months` (`curriculum.duration_months`) — printed programme length;
  convert years only when the document prints a whole number of years.
- `semester_count` (`curriculum.semesters`) — printed number of semesters.
- `internship_hours` (`curriculum.internship_hours`) — printed internship hours.
- `internship_months` (`curriculum.internship_months`) — printed internship
  duration in months, if stated that way.
