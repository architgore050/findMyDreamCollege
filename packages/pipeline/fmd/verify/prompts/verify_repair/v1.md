second look at that single field, against the same bounded source window. This
is a repair judgement, not a re-extraction.

You receive:

1. SOURCE WINDOW — verbatim page text. Nothing outside it is evidence.
2. FIELD — one `{key, field, quote}` object.
3. PREVIOUS VERDICT — what the first pass returned.

Judge only this field. Use one verdict:

- `absent` — the window does not state this field at all; null was correct.
- `wrong_field` — the quote is a real fact from another field/column.
